# Журнал типовых инцидентов

| Инцидент | Признак | Источник диагностики |
|---|---|---|
| Неиспользуемая переменная | Красная проверка `pylint` в PR | Шаг Static analysis |
| Недостаточные права публикации | `build` успешен, `deploy` не получает OIDC-токен | Журнал deploy и permissions |
| Битая ссылка | `mkdocs build --strict` завершился ошибкой | Шаг Build documentation |
| Старая версия после деплоя | Успешный workflow, прежняя страница | URL, время публикации и кэш |
