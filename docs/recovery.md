# Аварийное восстановление

1. Определите отказавший этап в журнале GitHub Actions и сохраните его номер.
2. Исправьте источник ошибки в отдельной ветке и откройте Pull Request.
3. После успешных проверок выполните слияние и дождитесь публикации.
4. Откройте сайт и проверьте версию и основные страницы.
